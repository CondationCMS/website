# CondationCMS

Welcome to the CondationCMS documentation.

CondationCMS is a lightweight, developer-friendly flat-file CMS for building fast, structured, and maintainable websites with Java. Content is stored in simple files, while templates, themes, extensions, and modules give you the flexibility to adapt the system to the requirements of your project.

This documentation guides you through the core concepts of CondationCMS—from installation and configuration to content creation, template development, the Manager application, and custom extensions.

New to CondationCMS? Start with the **Getting Started** guide to set up your first site. If you are already familiar with the basics, explore the individual sections to learn more about content structures, request processing, theming, modules, and advanced configuration.
